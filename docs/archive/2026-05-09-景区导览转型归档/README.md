# 景区导览转型归档

**归档日期**：2026-05-09
**归档原因**：项目转型为「灵山胜境 AI 数字人导览系统」后，以下规划文档与赛题方向不符，按 PRD 要求从默认路径移除。

---

## 背景说明

根据《灵山胜境AI数字人导览系统PRD-2026-05-05.md》和《景区导览服务AI数字人赛题适配改造方案-2026-05-04.md》的要求，项目需要从「桌面 AI 伴随/开发助手」收敛为「景区导览服务 AI 数字人」。

**明确不做/必须隐藏的内容**：
- ❌ 像素房间、办公室、家具编辑
- ❌ 桌宠娱乐化玩法
- ❌ 多 Agent 工作空间概念
- ❌ 通用聊天/开发助手语义
- ❌ 数值系统、人格快速反应层等底层架构

## 技术资产复用说明

虽然以上规划文档被归档，但项目中的**底层技术能力仍然保留**，只是从景区导览的默认路径中隐藏：

| 技术能力 | 复用方式 | 保留位置 |
|---------|---------|---------|
| Electron 桌面端 | 作为景区服务台终端 | `desktop/electron/` |
| Live2D 数字人 | 改为导游形象展示 | `front_end/src/components/live2d/` |
| ASR/TTS/语音链路 | 支持语音问答 | `desktop/electron/services/voice/` |
| Nanobot 后端 | 作为问答引擎 | `desktop/electron/services/chat/backends/` |
| 流式对话 | 支持实时导游讲解 | `desktop/electron/services/chat/` |
