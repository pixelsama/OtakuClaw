## 🎯 演示脚本 (最终版)

### 核心演示流程 (10分钟)

```
1. 打开应用 (30秒)
   ├─ 启动进入"灵山胜境 AI 导游"游客端
   └─ 展示数字人和欢迎界面

2. 切换管理端 (1分钟)
   ├─ 展示官方资料包已导入
   │  ├─ 22 个点位
   │  ├─ 3 类官方路线
   │  └─ 140447 条行为数据
   └─ 返回游客端

3. 游客语音问答 (3分钟)
   ├─ 问："第一次来灵山胜境，两小时怎么逛比较好？"
   │  ├─ 系统生成 2 小时路线卡
   │  └─ 数字人口播推荐理由
   ├─ 问："灵山大佛有什么特色？"
   │  ├─ 系统基于官方资料讲解
   │  └─ 展示来源追溯
   └─ 问："九龙灌浴适合带孩子看吗？"
      ├─ 系统结合亲子路线回答
      └─ 游客点踩，记录反馈

4. 管理端分析 (2分钟)
   ├─ 交互日志
   │  ├─ 查看刚才的问题
   │  ├─ 查看命中来源
   │  └─ 查看延迟和评价
   ├─ 知识库管理
   │  └─ 演示知识更新
   └─ 数据大屏
      ├─ 展示服务人次
      ├─ 展示热门问题
      ├─ 展示满意度
      └─ 展示游客画像

5. 评测中心 (2分钟)
   ├─ 运行 100 条评测题
   ├─ 展示准确率报告
   ├─ 展示延迟报告
   └─ 展示错题分析

6. 总结 (1.5分钟)
```
