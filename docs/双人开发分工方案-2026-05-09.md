## 1. 分工原则

### 1.1 核心原则

1. **前后端分离**：开发者 A 负责后端服务与数据，开发者 B 负责前端界面与交互
2. **技能匹配**：根据两人的技术栈特长分配任务
3. **低耦合**：两人任务尽量减少代码冲突
4. **高内聚**：每人负责的功能模块尽量集中
5. **可并行**：两人可以同时独立开发的任务优先

### 1.2 分工优势

| 优势 | 说明 |
|-----|------|
| **减少冲突** | 前后端分离，减少 Git 合并冲突 |
| **责任清晰** | 每人明确负责自己的模块，易于问责 |
| **并行效率** | 两人可同时开发，互不阻塞 |
| **技术聚焦**：每人专注自己擅长的领域，提高效率 |

### 1.3 协作要求

1. **每日站会**：15分钟同步进度和问题
2. **接口先行**：先定义 IPC 接口，再各自开发
3. **代码审查**：关键代码提交前互相审查
4. **共享文档**：及时更新设计文档和接口文档
5. **问题上报**：遇到阻塞问题立即沟通

## 4. 并行开发策略

### 4.1 接口先行原则

为避免阻塞，**所有新增功能必须先定义 IPC 接口**，然后再并行开发：

```javascript
// 示例：路线推荐 IPC 接口定义
// ipc/scenicGuide.js
ipcMain.handle('scenic-guide:plan-route', async (_event, request) => {
  // 参数：{ interests, duration, crowd, energy, specialNeeds }
  // 返回：{ ok: true, routes: [...] }
  // 或：{ ok: false, error: {...} }
});
```

**接口定义规范**：
1. 参数结构清晰
2. 返回值统一格式
3. 错误信息详细
4. 注释完整

### 4.2 Mock 数据策略

前端开发时，如后端接口未就绪，使用 Mock 数据：

```javascript
// front_end/src/services/scenicGuideMock.js
export const mockRoutePlanningResult = {
  ok: true,
  routes: [
    {
      routeId: 'official-history-culture-6h',
      name: '历史文化爱好者路线',
      durationMinutes: 360,
      spots: [...],
      recommendationReason: '...'
    }
  ]
};
```

## 9. 附录：接口定义模板

### 9.1 新增接口模板

```javascript
// desktop/electron/ipc/scenicGuide.js

ipcMain.handle('scenic-guide:your-api-name', async (_event, request = {}) => {
  try {
    // 1. 参数验证
    if (!request.requiredParam) {
      return {
        ok: false,
        error: {
          code: 'invalid_params',
          message: 'Missing required parameter: requiredParam'
        }
      };
    }

    // 2. 调用服务
    const result = await yourService.yourMethod(request);

    // 3. 返回结果
    return {
      ok: true,
      data: result
    };
  } catch (error) {
    // 4. 错误处理
    return {
      ok: false,
      error: {
        code: error.code || 'service_error',
        message: error.message || 'Operation failed'
      }
    };
  }
});
```

### 9.2 前端调用模板

```javascript
// front_end/src/services/scenicGuideBridge.js

async callYourApiName(request) {
  if (!this.desktopMode) {
    // Web fallback 或 Mock
    return mockYourApiResult(request);
  }

  try {
    const result = await ipcRenderer.invoke('scenic-guide:your-api-name', request);
    if (result?.ok) {
      return result.data;
    } else {
      throw new Error(result?.error?.message || 'API call failed');
    }
  } catch (error) {
    console.error('scenic-guide:your-api-name failed:', error);
    throw error;
  }
}
```
