# 灵山胜境官方资料包导入说明

本目录只记录导入约束和开发说明，不提交比赛官方原始资料文件。

比赛官方资料包应由管理员在应用内选择本机目录导入。当前导入器要求目录中包含以下文件名：

1. `灵山胜境 景点结构化数据集.docx`
2. `灵山胜境：历史、文化、景点特色与个性化游览指南.docx`
3. `景点景区旅游数据行为分析数据.xlsx`

导入流程只读取原始文件，并在应用数据目录保存 manifest 和结构化摘要。仓库根目录与 `docs/scenic-demo/official-lingshan/raw/` 已加入 `.gitignore`，避免把官方原始 Docx/Xlsx 误提交。

当前验收口径：

1. 识别 22 个官方点位：`LS-001` 至 `LS-016`、`NH-001` 至 `NH-006`。
2. 识别 3 条官方推荐路线：历史文化、自然风光、亲子家庭。
3. 识别行为数据表 17 个字段和 140447 条游客行为记录。
