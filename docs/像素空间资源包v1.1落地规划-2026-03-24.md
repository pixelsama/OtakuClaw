# 像素空间资源包 v1.1 落地规划

更新时间：2026-03-24  
适用范围：Pixel Room 资源包（背景/角色/家具）导入、运行时装配、GUI 编辑与导出

## 1. 背景与结论

基于当前代码状态，`Pixel Room` 尚未具备“上传 zip 资源包并动态加载”的能力。  
现有 zip 导入能力仅覆盖 Live2D 模型，不覆盖像素空间资源包。

本规划目标是：在不推翻现有 Pixel Room 渲染链路的前提下，以最小改造落地可用的 v1.1 资源包体系。

## 2. 目标与非目标

### 2.1 目标

1. 支持导入像素空间资源包 `.zip`。
2. 支持用户上传并配置：
   - 空间背景图
   - 角色像素图（多状态、可动画）
   - 家具像素图（可动画）
3. 支持运行时启用/禁用资源包，并回退到内置资源。
4. 支持 GUI 编辑并导出符合契约的资源包。

### 2.2 非目标（本期不做）

1. 复杂粒子特效编辑器。
2. 多包混合渲染（本期仅支持单 active pack）。
3. 跨设备云同步资源包（本期仅本地存储）。

## 3. v1.1 契约补充（在 v1 基础上增量）

建议保持 `schemaVersion: 1`，新增 `contractRevision: "1.1"`，以“可选字段增量”方式兼容 v1。

### 3.1 新增/补充字段

1. `scene.backdrop.assetKey`：房间主背景。
2. `areas.<areaId>.slots[]`：区域站位点（与当前 area/slot 机制对齐）。
3. `areas.<areaId>.immersiveBackdrop`：沉浸模式取景参数（`assetKey/x/y/size/position`）。
4. `characters.<characterId>.states.<businessState>`：
   - `assetKey`
   - `frameIndex`（可选）
   - `animation`（可选，`frames` 或 `fromFrame/toFrame/fps`）
5. `furnitureCatalog[]`（新增核心）：
   - 基础：`id/label/left/top/width/zIndex/aspectRatio`
   - 显隐：`visibleWhenStates/hiddenWhenStates`
   - 变体：`stateVariants`
   - 分层：`layers[]`（每层 `assetKey/zIndex/opacity/frameIndex/animation/stateVariants`）
6. `themes[]`：主题与家具组合映射（`furnitureIds`）。

### 3.2 最小示例（结构示意）

```json
{
  "schemaVersion": 1,
  "contractRevision": "1.1",
  "packId": "com.otakuclaw.pixel.demo",
  "version": "1.1.0",
  "assets": {
    "bg.office.main": { "path": "assets/backgrounds/office.webp", "type": "image" },
    "char.star.work": { "path": "assets/characters/star_work.webp", "type": "spritesheet", "cols": 8, "rows": 5 },
    "furniture.desk.main": { "path": "assets/furniture/desk.webp", "type": "image" }
  },
  "scene": { "backdrop": { "assetKey": "bg.office.main" } },
  "characters": {
    "star": {
      "states": {
        "idle": { "assetKey": "char.star.work", "frameIndex": 0 },
        "writing": { "assetKey": "char.star.work", "animation": { "fromFrame": 0, "toFrame": 39, "fps": 8 } }
      }
    }
  },
  "furnitureCatalog": [
    {
      "id": "desk",
      "label": "Desk",
      "left": 10,
      "top": 45,
      "width": 22,
      "zIndex": 8,
      "layers": [{ "id": "desk-main", "assetKey": "furniture.desk.main", "zIndex": 8 }]
    }
  ]
}
```

## 4. 导入器最小落地清单（MVP）

### 4.1 主进程能力

1. 新增 `PixelPackLibrary`：
   - 解压 zip（复用现有 unzip/powershell 方案）
   - 读取 `manifest.json`
   - 校验 schema 与路径安全（拒绝 `../`）
   - 入库到 `userData/pixel-packs/<packId>/<version>/`
2. 新增 IPC：
   - `pixel-packs:list`
   - `pixel-packs:import-zip`
   - `pixel-packs:validate`
   - `pixel-packs:activate`
   - `pixel-packs:remove`
3. 设置持久化：
   - `ui.pixelPack.activePackId`
   - `ui.pixelPack.activeVersion`
   - `ui.pixelPack.overrides`（编辑器运行态补丁）

### 4.2 运行时装配

1. 新增“资源覆盖层”：
   - 先查 active pack 资产
   - 失败回退内置 `OFFICE_SCENE_ASSET_REGISTRY`
2. 新增“场景配置装配器”：
   - 把 manifest 转成当前 `resolveOfficeSceneState` 可消费的结构。
3. 角色状态映射改造：
   - 将 `resolveOfficeOccupantSprite` 从硬编码切到“pack 优先，内置兜底”。

## 5. 编辑页最小落地清单（MVP）

### 5.1 页面能力

1. 资源管理：上传背景/角色/家具图（先支持 `png/webp`，动画走 spritesheet 参数）。
2. 角色状态映射：`idle/writing/researching/executing/error... -> assetKey`。
3. 家具编辑：新增/删除、位置、尺寸、层级、显隐规则、动画参数。
4. 区域背景：配置 `immersiveBackdrop` 的 `assetKey/x/y/size/position`。
5. 预览：在 Pixel Room 实时预览状态切换。
6. 导出：生成 `manifest.json` 并打包 zip。

### 5.2 最小 UI 结构

1. 资源包管理面板（导入/激活/删除/错误详情）。
2. 场景资产面板（背景、角色、家具）。
3. 家具编辑面板（属性 + 图层）。
4. 状态映射面板（角色/家具）。
5. 导出面板（校验结果 + 导出 zip）。

## 6. 实施阶段（建议）

### Phase 1（3-4 天）：导入与激活

1. 完成 `PixelPackLibrary + IPC + settings`。
2. 实现 active pack 资产覆盖与内置回退。
3. 提供只读启用能力（无编辑器）。

### Phase 2（4-6 天）：编辑器 MVP

1. 角色状态映射编辑。
2. 家具属性与图层编辑。
3. 区域背景编辑与预览。

### Phase 3（2-3 天）：导出与回归

1. zip 导出与导入回放验证。
2. 错误提示与兼容回退完善。
3. E2E 冒烟脚本补齐（导入->激活->预览->导出->再导入）。

## 7. 验收标准

1. 用户可导入合法 zip 并成功激活。
2. 角色状态切换时，资源包角色素材正确变化（含动画）。
3. 家具在多状态下正确切换素材，遮挡关系可控。
4. 配置错误不会导致运行时崩溃，能回退到内置资源。
5. 导出的 zip 可被同版本客户端再次导入并一致渲染。

## 8. 风险与回滚

1. 风险：资源路径安全与包体校验不严可能引入安全问题。  
   对策：严格路径穿越检查 + schema 校验失败即拒绝激活。
2. 风险：动态图规格不统一导致渲染异常。  
   对策：统一优先 spritesheet；编辑器内做 `cols/rows/frame` 校验。
3. 风险：新包配置缺字段造成展示空白。  
   对策：pack -> 内置资源双层回退，保证至少可用。

## 9. 产出物清单

1. 资源包导入器与 IPC。
2. v1.1 manifest 校验器（含错误码）。
3. Pixel Room 运行时 pack 装配层。
4. 编辑页 MVP（导入/编辑/预览/导出）。
5. 回归测试与操作文档。
