# 像素空间资源包契约（v1）

更新时间：2026-03-24  
适用范围：Pixel Room / 深度交互（Immersive）资源组织、导入、校验与 GUI 配置映射

## 1. 目标

本契约用于统一以下能力：

1. 在 GUI 中配置“区域背景与深度交互背景”（含不同区域不同取景/素材）
2. 将像素空间美术资源（背景、角色状态、家具状态、动效）打包为可分发资源包
3. 保证资源包跨版本可校验、可回退、可兼容

## 2. 核心决策

### 2.1 容器格式

采用 **ZIP 容器**，不自研二进制格式。

- 推荐包扩展名：`.zip`
- 实际文件结构：标准 ZIP（便于调试、解包、CI 校验）

结论：对外与对内都统一为“ZIP + manifest 契约”。

### 2.2 契约中心

`manifest.json` 是唯一契约源。  
运行时行为（素材映射、状态切换、区域深度交互背景）全部由 manifest 决定。

## 3. 包目录规范（v1）

```text
<pack-id>.zip
  manifest.json
  assets/
    backgrounds/
    immersive/
    characters/
    furniture/
    fx/
```

约束：

1. 所有路径必须为相对路径，且限定在包内（禁止 `../`）
2. 建议图片格式：`webp/png`，动画可用 spritesheet 或序列帧
3. v1 不要求音频资源；后续版本可扩展 `audio/`

## 4. Manifest 结构（v1）

## 4.1 顶层字段

```json
{
  "schemaVersion": 1,
  "packId": "com.otakuclaw.pixel.classic",
  "name": "Pixel Classic Pack",
  "version": "1.0.0",
  "engine": ">=0.2.1",
  "author": "Your Name",
  "description": "Optional",
  "assets": {},
  "areas": {},
  "characterStates": {},
  "furnitureStates": {}
}
```

字段说明：

1. `schemaVersion`: 资源包契约版本（v1 固定为 `1`）
2. `packId`: 全局唯一 ID（建议反向域名）
3. `version`: 资源包版本（SemVer）
4. `engine`: 应用兼容范围（语义版本表达式）

## 4.2 assets（全局素材注册表）

```json
{
  "assets": {
    "bg.office.main": { "path": "assets/backgrounds/office_main.webp", "type": "image" },
    "bg.immersive.desk": { "path": "assets/immersive/desk_close.webp", "type": "image" },
    "char.star.idle": { "path": "assets/characters/star_idle.webp", "type": "image" },
    "char.star.working": { "path": "assets/characters/star_working.webp", "type": "spritesheet", "cols": 8, "rows": 5 }
  }
}
```

说明：

1. 运行时通过 `assetKey` 引用素材，不直接散落硬编码路径
2. `type` 支持：`image` / `spritesheet`

## 4.3 areas（区域定义与深度交互背景）

```json
{
  "areas": {
    "desk": {
      "label": "Desk",
      "sceneBackgroundAsset": "bg.office.main",
      "immersiveBackdrop": {
        "assetKey": "bg.immersive.desk",
        "x": 21,
        "y": 47,
        "size": "230%",
        "position": "21% 47%"
      }
    },
    "lounge": {
      "label": "Lounge",
      "immersiveBackdrop": {
        "assetKey": "bg.immersive.lounge",
        "x": 59,
        "y": 18,
        "size": "210%"
      }
    }
  }
}
```

规则：

1. `x/y` 范围 `0~100`，语义为背景取景中心点百分比
2. `position` 优先级高于 `x/y`
3. 未配置 `immersiveBackdrop` 时，回退为：  
   区域点位 `x/y` + 默认背景素材

## 4.4 characterStates（角色状态映射）

```json
{
  "characterStates": {
    "star": {
      "idle": "char.star.idle",
      "writing": "char.star.working",
      "researching": "char.star.working",
      "executing": "char.star.working",
      "error": "char.star.error"
    }
  }
}
```

## 4.5 furnitureStates（家具状态映射）

```json
{
  "furnitureStates": {
    "serverRoom": {
      "idle": "furniture.server.idle",
      "executing": "furniture.server.active",
      "error": "furniture.server.alert"
    }
  }
}
```

## 5. GUI 配置映射（必须支持）

GUI 不直接编辑复杂 JSON，按以下面板映射：

1. 资源包管理
   1. 导入 `.zip`
   2. 启用/禁用/卸载
   3. 校验错误展示（缺失资源、版本不兼容、字段非法）
2. 区域背景设置
   1. 选择区域（Desk/Lounge/SyncDock/BugNook）
   2. 选择深度交互背景素材（assetKey）
   3. 调整 `x/y/size`（滑块）
   4. 可选高级输入 `position`
3. 状态映射设置
   1. 角色状态 -> assetKey
   2. 家具状态 -> assetKey

GUI 保存后应生成符合本契约的 `manifest.json`。

## 6. 导入与校验规则（v1）

导入时必须校验：

1. `manifest.json` 存在且 JSON 可解析
2. `schemaVersion === 1`
3. `packId/version/engine` 字段存在且合法
4. 所有 `assetKey` 可在 `assets` 中解析
5. 所有 `path` 在包内且无路径穿越
6. `x/y` 在 `0~100`；`size`/`position` 为合法 CSS 值

若校验失败：

1. 不激活该包
2. GUI 展示逐条错误
3. 保留当前生效包（不影响运行）

## 7. 运行时回退策略

任意字段缺失或资源加载失败时按以下顺序回退：

1. 区域级配置
2. 包级默认配置（若定义）
3. 内置默认资源（应用内资源表）

原则：运行时不崩溃，至少可展示默认背景与默认状态。

## 8. 兼容与演进

### 8.1 v1 到 v2

当新增字段或能力时：

1. 递增 `schemaVersion`
2. 提供迁移器（v1 -> v2）
3. GUI 保留“升级并另存为”流程

### 8.2 版本策略

1. 资源包 `version`：包内容版本（SemVer）
2. 契约版本 `schemaVersion`：格式版本
3. 应用兼容 `engine`：运行时版本门槛

## 9. 推荐实践

1. 一个包内尽量只维护一种视觉主题（便于回滚）
2. `assetKey` 命名采用层级语义，如 `bg.immersive.desk.night`
3. GUI 编辑后先本地预览，再导出 `.zip`
4. CI 增加资源包 lint（JSON schema + 文件存在性）
