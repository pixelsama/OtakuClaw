# 跨功能集契约清单与版本策略

更新时间：2026-03-27

## 1. `conversation:event` 统一 envelope schema

- Schema 版本：`2026-03-27.v1`
- 契约定义：`desktop/electron/contracts/conversationEnvelopeContract.js`
- 统一字段：
  - `schemaVersion`
  - `timestamp`
  - `channel` (`chat|voice|system|office|value`)
  - `type`
  - `agentId/backend/routeKey/sessionId/sessionNamespace/profileId/turnId/streamId`
  - `payload` (plain object)

主进程在发射 envelope 前执行 normalize + validate；首次发现非法 envelope 会告警（去重）。

## 2. 兼容与下线策略

历史镜像通道保留为兼容层（仅在 `OPENCLAW_ENABLE_LEGACY_STREAM_EVENTS` 打开时发射）：

- `chat:stream:event` -> 替代：`conversation:event (channel=chat)`
- `voice:event` -> 替代：`conversation:event (channel=voice)`
- 目标下线日期：`2026-06-30`

开启 legacy mirror 时会输出一次性 deprecation warning，提醒迁移。

## 3. 注册化装配（主进程 / 渲染层）

### 3.1 主进程 `main.js`

已把大段 IPC 注册逻辑收敛到 feature registry：

- 注册入口：`desktop/electron/bootstrap/featureIpcRegistry.js`
- 释放入口：`disposeFeatureIpcModules(...)`
- 目标：把 `office/value/settings/download/updater/live2d/pixelpack/avatar/screenshot/nanobot/acp/voice-model` 模块按功能集集中装配，降低 `main.js` 编排复杂度。

### 3.2 渲染层 `App.jsx`

已把会话事件订阅编排改为功能装配 hook：

- `front_end/src/hooks/app/useDesktopConversationAssemblies.js`
- 目前已收敛：
  - office activity hint 订阅
  - permission request queue 订阅

后续新增会话类功能集时，优先在该 hook 的 assembly registry 中注册，而不是继续堆叠到 `App.jsx`。
